
# AI Study Assistant

A simple Python-based study helper built using Streamlit.

## Features

1. Explain a Topic – Displays prepared explanations for selected topics.
2. Summarize Notes – Selects important sentences using keyword frequency.
3. Generate Quiz Questions – Creates three basic practice questions from a topic.

## Technologies Used

- Python
- Streamlit
- Regular Expressions
- Collections Counter

## Installation

```bash
python -m pip install -r requirements.txt
```

## Run the Application

```bash
python -m streamlit run app.py
```

## Project Note

This beginner-level local study assistant uses prepared explanations, keyword-based text processing, and question templates. It does not connect to a generative AI model or use an external API.
