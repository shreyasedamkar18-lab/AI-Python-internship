# Student Performance Prediction System

This project uses Machine Learning to estimate a student's final score based on study hours, attendance, and previous academic performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit

## Features
- Interactive student input sliders
- Final score prediction using Linear Regression
- Dataset overview
- Model evaluation using Mean Absolute Error
- Study hours vs final scores visualization

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the application:

python -m streamlit run app.py

## Disclaimer
This is an educational project using a small sample dataset. Predictions are estimates and should not be treated as reliable assessments of actual student performance.
